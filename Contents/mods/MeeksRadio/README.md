# Radio Frequencies

Radio Frequencies is a server-authoritative music, announcement, emergency-alert, lore, event, and community broadcast system for Project Zomboid Build 42 multiplayer servers.

## Version 0.12.0

- Press F7 while carrying, standing near, or using a tuned radio to open the interface.
- Listener View provides readable broadcast history, approved tracks, favorites, and player requests.
- Track requests use the station currently open in Listener View; a powered tuned receiver remains required for hearing music.
- Station operations provide a searchable approved catalog and synchronized queue management.
- Authorized administrators can manage DJs, broadcasts, templates, emergency playback, and station controls.
- Listener, Station, and Admin screens use the same Command Center layout and themes as Survivor League.
- The server remains authoritative for permissions, queues, broadcasts, and playback state.
- Broadcasts appear in global in-game chat and remain in per-station history.
- Overhead broadcast text is disabled by default and admin names are not included.
- Dedicated relay markers support Discord announcements through the Meeks Protocol bridge.

## Installation

Add Workshop item `3785340353` and Mod ID `MeeksRadio` to the server. Restart the client and server after updating. Version 0.12.0 uses protocol 9; every client and the server must use the same package.

## Compatibility

- Project Zomboid Build 42.20+
- Multiplayer and hosted/co-op sessions
- Selectable Project Zomboid, Meeks Protocol, and Military interface themes
